# SideCal

Free sidebar calendar for macOS. Time-block by dragging, see your next event in the menu bar.

**Website and docs: <https://kacpergorec.github.io/sidecal/>**

## Install

Needs macOS 14+, Xcode Command Line Tools and [Rust](https://rustup.rs).

```bash
./install.sh
```

No prebuilt download yet.
