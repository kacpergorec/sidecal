What it does

A side calendar built for time blocking.

Everything you need to plan the day in the margin of your screen, and nothing that gets in the way of your work.

Hides at the edge, leaves a trace

Move the mouse away and the sidebar slides to the screen edge. A faint strip keeps your events and the current time in view; touch the edge and it opens again.

Block time by dragging

Drag on the timeline to create an event, drag an entry to move it, drag its edge to resize. Everything snaps to 15 minutes.

Menu bar countdown

"Design review (23m left)" while an event runs, "Standup in 12m" before the next one. Always one glance away.

Twelve colours, two themes

Colour a single event or a whole calendar. Each colour has a light and a dark variant.

Light, dark, or auto

Follows macOS, or pick one. Optional island mode floats the sidebar as a rounded card.

7 MBbinary, about 100 MB RAM with WebKit. No Electron, no npm.

Get started

Three steps, one command.

  1. Build and install

    Clone the repository, then run ./install.sh. It builds the app and puts it in Applications.

  2. Allow calendar access

    macOS asks once. SideCal reads your calendars locally, with no account and no network.

  3. Drag to plan

    Open the sidebar from the menu bar and drag out your first block of time.

Needs macOS 14 or newer, the Xcode Command Line Tools and Rust. Full instructions in the documentation.

Questions

Good to know.

Is SideCal really free?

Yes. It is open source under the Apache License 2.0: use it, change it, share it, even commercially. If you redistribute it, keep the licence and the NOTICE file that credit Kacper Górec.

Which calendars does it show?

Every calendar in the macOS Calendar app: iCloud, Google, Exchange, CalDAV and local ones. Add an account in System Settings and it appears in SideCal.

Does it send my data anywhere?

No. The app contains no network code and no analytics. Your events stay in the system calendar; colours, hidden events and settings live in one JSON file on your Mac.

Is there a download?

Not yet. The app is not notarized with an Apple Developer ID, so you build it yourself with one command. It takes a few minutes the first time.

Does it work on Apple Silicon?

It should, but it has only been tested on an Intel Mac with macOS 15. Reports from other machines are welcome.

How is it different from a calendar app?

It does one thing: keep today in view while you work. It hides when you do not need it, shows the next event in the menu bar, and lets you block time without opening a full calendar window.
