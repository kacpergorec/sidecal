AI assistants

Let your AI plan your day.

SideCal doubles as a local MCP server, the open standard assistants use to talk to tools. Claude, Cursor and any other MCP client can read your calendar and time-block it. It runs locally, so nothing leaves your Mac.

Connect it

Point any MCP client at this command. Setup for Claude Code, Claude Desktop and Cursor is in the docs.

MCP server command
$ /Applications/SideCal.app/Contents/MacOS/sidecal --mcp

Claude Desktop extension (.mcpb)

Setup guide

What your AI can do

  • List your calendars
  • Read events in a date range
  • Add events (time blocking)
  • Move, resize and rename events

It cannot delete events. Events and calendars you hide in SideCal stay hidden from the assistant.

Get started

Download it or build it.

Download the app

No tools needed. Grab the zip for your Mac from Releases.

  1. Download SideCal-apple-silicon.zip (M1 and newer) or SideCal-intel.zip.
  2. Unzip and drag SideCal.app to Applications.
  3. Right-click it, choose Open, then Open again. macOS asks once because the app is not notarized.
Download latest release

Build from source

Needs macOS 14+, Xcode Command Line Tools and Rust.

Terminal
$ git clone https://github.com/kacpergorec/sidecal.git
$ cd sidecal
$ ./install.sh

Questions

Frequently asked questions

What is SideCal?

SideCal is a free, open-source sidebar calendar for macOS. It shows today's Apple Calendar as a 24-hour timeline on the edge of your screen, adds a countdown to your next event in the menu bar, and lets you time-block your day by dragging events.

Is SideCal free?

Yes. SideCal is free and open source under the Apache License 2.0. It has no ads, no account and no subscription.

How do I plan my day with it?

Open SideCal and drag on an empty part of the timeline to create an event. Drag an entry to move it, or drag its top or bottom edge to resize it. Changes are saved to your Apple Calendar.

Which calendars does SideCal work with?

Every calendar in the macOS Calendar app: iCloud, Google, Exchange, CalDAV and local calendars. Add the account in System Settings and it appears in SideCal.

Does SideCal show my next meeting in the menu bar?

Yes. The menu bar shows the running event with the time left, for example “Design review (23m left)”, or the next event, for example “Standup in 12m”. You can hide the title or the duration in Settings.

Is my calendar data private?

Yes. SideCal has no telemetry and no analytics. It reads your events locally through Apple's EventKit and keeps its own settings in one JSON file on your Mac. The only network call it can make is an optional update check, which is off by default and downloads one small file.

Can AI assistants use SideCal?

Yes. Run sidecal --mcp and SideCal acts as a local MCP server over stdio, with no network. Any MCP client, such as Claude or Cursor, can list calendars, read events, add events and move or rename them. It cannot delete events, and events you hide in SideCal stay hidden from the assistant.

Does SideCal update itself?

Optionally. Turn on Check for Updates Automatically in Settings, or use Check for Updates in the menu bar menu. SideCal reads one small file (latest.json) from GitHub Pages, and installing an update always needs your click. With the setting off it makes no network calls.

Which Macs and macOS versions are supported?

macOS 14 (Sonoma) or newer. SideCal is tested on an Intel Mac running macOS 15. Apple Silicon should work but is untested.

How do I install SideCal?

Download SideCal-apple-silicon.zip or SideCal-intel.zip from the latest GitHub release, unzip it and drag SideCal.app to Applications. Or build it yourself: clone the repository and run ./install.sh (needs the Xcode Command Line Tools and Rust).

Can I modify or fork SideCal?

Yes. SideCal is licensed under Apache 2.0, so you may change and redistribute it, including commercially. Keep the LICENSE and NOTICE files that credit the author, Kacper Górec, and mark your changes.

Who makes SideCal?

SideCal is made by Kacper Górec and written in Rust with Tauri.
