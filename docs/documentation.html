Documentation

Everything about installing, using and configuring SideCal, a free sidebar calendar for macOS.

Install

Two options: download the app from GitHub Releases, or build it from source.

Download (no tools needed)

  1. Open the latest release and download SideCal-apple-silicon.zip (M1 and newer) or SideCal-intel.zip.
  2. Unzip it and drag SideCal.app to Applications.
  3. Right-click the app, choose Open, then Open again. The app is not notarized with an Apple Developer ID, so macOS asks once.

"SideCal is damaged": run xattr -dr com.apple.quarantine /Applications/SideCal.app in Terminal, then open it again.

Build from source: requirements

  • macOS 14 (Sonoma) or newer
  • Xcode Command Line Tools: xcode-select --install
  • Rust (stable) from rustup.rs

Build and install

Clone the repository, open a terminal in its folder and run:

./install.sh
open /Applications/SideCal.app

The first build compiles about 400 Rust crates and takes a few minutes. Later builds take about a minute. To build without installing, run ./build-app.sh; it creates SideCal.app in the project folder.

Tested on: an Intel Mac with macOS 15. Apple Silicon should work but is untested.

First launch

  1. macOS asks for calendar access. Choose Allow Full Access. Without it the sidebar shows a waiting message.
  2. SideCal has no Dock icon. It lives in the menu bar and shows your next event there.
  3. Click the menu bar text to show or hide the sidebar. Right-click it for Settings and Quit.
  4. To start at login, copy the app to /Applications first, then turn on Launch at Login in Settings → General.

After updating: the app is signed ad hoc, so macOS sees every rebuilt copy as a new app and asks for calendar access once more.

Using the sidebar

Do thisTo get this
Drag on an empty spot of the timelineCreate an event. A form opens with the range you dragged.
Click the + buttonCreate an event at the next free half hour (if Suggest Events is on).
Click an entryEdit its title, calendar and times.
Drag an entryMove it. Snaps to 15 minutes.
Drag the top or bottom edge of an entryChange its start or end.
Right-click an entryChoose a colour, hide the event, or delete it (asks twice).
Right-click the empty boardReload, show or hide hidden events, open Settings.

Events from calendars that are read-only (holidays, subscriptions) can be coloured and hidden but not edited. Editing or deleting a repeating event changes only the occurrence you touched.

Colours

Right-click an entry to give that event one of twelve colours. To recolour a whole calendar, open Settings → Calendars and click its colour square. Every colour has a light and a dark variant, and text switches between black and white for contrast. Colours you choose are stored in SideCal's settings, not in your calendar.

Calendar priority

In Settings → Calendars, drag the handle to reorder calendars. When events overlap, the calendar higher in the list takes the left column and is drawn on top. It is also the default calendar for new events.

Hiding events

Right-click → Hide event removes an entry from the sidebar and the menu bar countdown. The event stays in your calendar. Right-click the board and choose Show hidden events to see them again, drawn faded with a dashed outline.

Auto-hide and edge preview

With Auto-Hide on, the sidebar slides to the screen edge about a quarter of a second after the mouse leaves it. With Edge preview on, a thin strip stays behind: your events as faint bars, with a dot and a line for the current time. The running event stays at full strength.

Only pushing the mouse against the screen edge itself opens the sidebar; resting on the strip does not. Turn Edge preview off and the sidebar disappears completely instead; the screen edge still brings it back. You can set the strip's width (7 to 40 px) and opacity in Settings → Sidebar.

Shortcuts

Global shortcuts work in any app. Click a field in Settings → Shortcuts and press the new combination (include Ctrl, Alt or Cmd).

DefaultAction
Ctrl Alt Cmd SShow or hide the sidebar
Ctrl Alt Cmd NNew event
Ctrl Alt Cmd ,Open settings

Esc closes the event form and menus.

Settings

Open Settings from the gear in the sidebar header, the menu bar item, the board's right-click menu or the shortcut. The window can be resized.

TabWhat you can change
CalendarsShow or hide calendars, drag to set priority, change a calendar's colour, mark it as productive.
GeneralLaunch at Login. Show Event Title and Show Event Duration in the menu bar. Suggest Events.
AppearanceLight, dark or auto. Island Mode. Show Header, Weekday and Date. 12-hour clock (hours 1 to 12, no AM/PM). Time indicator. All-day events. Highlight Active Event.
SidebarLeft or right edge, width, Keep Above Other Windows, Auto-Hide, and the Edge preview (on or off, width, opacity).
ShortcutsUse Global Hotkeys, and the three shortcuts.
ProductivityHours spent in calendars marked as productive, today and this week. Click a number to copy it.

Hover the ? next to an option for a short explanation.

Your data

  • Events stay in the system calendar database. SideCal reads and edits them through Apple's EventKit.
  • Settings, custom colours and hidden events are stored in ~/Library/Application Support/com.kacpergorec.sidecal/settings.json.
  • Launch at Login writes ~/Library/LaunchAgents/com.kacpergorec.sidecal.plist; turning it off removes the file.
  • SideCal contains no network code and no analytics.

To reset everything, quit SideCal and delete the settings.json file.

Troubleshooting

The sidebar says "Waiting for calendar access"

Open System Settings → Privacy & Security → Calendars and allow SideCal full access. This happens again after every rebuild.

I can't find the sidebar

It may be auto-hidden: push the mouse against the screen edge, or press the show/hide shortcut, or click the menu bar text. If the menu bar is crowded, macOS can hide the item; close some other menu bar apps.

A shortcut does nothing

Check that Use Global Hotkeys is on (Settings → Shortcuts) and that another app is not using the same combination.

An event lost its colour or reappeared

Colours and hidden flags follow the event's identifier. Some calendar providers issue a new identifier after a sync, which resets them.

Building and contributing

The app is Rust and Tauri on the outside and plain HTML, CSS and JavaScript on the inside, with no bundler and no npm.

FileRole
src/calendar.rsEventKit bridge: access, read, create, update, delete
src/main.rsWindows, menu bar item, shortcuts, auto-hide and slide animation
src/settings.rsSettings model and persistence
ui/index.htmlThe sidebar
ui/settings.htmlThe settings window

After changing src/ or ui/, run ./build-app.sh. Contributions are welcome: see CONTRIBUTING.md in the repository.
